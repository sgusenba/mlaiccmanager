Backup & Restore

Download Backup

Saves all data of this competition as one zip file:

  • competitors, starts and results (data.json)
  • active and edited disciplines (competition.json)
  • teams (teams.json)
  • meet days, relays and lane assignments (relays.json)
  • meet name, venue, host and dates (meet.json)

The file contains personal data of the competitors — keep it safe.

Restore Backup

Replaces all current data with the data of a backup zip file. Data that is not in the backup (e.g. teams) is removed.

Before restoring, the current data is saved on the server in the backups/ folder, so the restore can be undone.

Automatic External Backup

Sends a backup to a backup receiver (java -jar mlaiccmanager.jar --backup-server) after every change, once the data has been quiet for the quiet time, and at the latest the maximum delay after the first change that has not been backed up.

This address is not on a private network and not HTTPS, so the token and the backup travel unencrypted. Put the receiver behind an HTTPS reverse proxy.
