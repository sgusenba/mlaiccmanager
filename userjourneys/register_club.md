Take a configured meet with rankings, some competitors are already registered.
a club sends its entries: several competitors with the rankings each one starts in
the organiser adds them all at once (bulk add), each with their starts
every competitor and every start exists afterwards, with unique start ids

Variation 1:
one of the competitors starts twice in the same discipline: bulk add takes each discipline once per row,
the second start is added in the Starts section and gets the next start number

Variation 2:
one of the rankings is a sum (e.g. Remington): the competitor gets a start in each discipline of the sum

Variation 3:
one entry names a ranking the meet does not have: the row is marked and nothing is added until it is corrected
